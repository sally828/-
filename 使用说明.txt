===================================================
   Anna's Archive 书目自动搜索工具  使用说明
===================================================

【第一步：安装环境】（只需做一次）
---------------------------------------------------
确保已安装 Python 3.11+，然后在终端/命令行运行：

    pip install playwright openpyxl
    playwright install chromium


【第二步：准备书单文件】
---------------------------------------------------
方法 A：从你的表格/Excel 导出
  1. 把书单另存为 CSV（UTF-8 编码）
  2. 将文件重命名为 books_input.csv
  3. 确保列顺序为：序号, 分类, 原书名, 状态, 找到书名

方法 B：从纯文本（制表符分隔）导入
  1. 把书单复制粘贴到 books_raw.txt（保存为 UTF-8）
  2. 运行：python convert_to_csv.py
  3. 自动生成 books_input.csv


【第三步：运行搜索】
---------------------------------------------------
    python search_anna.py

  - 会打开一个真实的 Chrome 浏览器窗口（可以看到操作过程）
  - 每搜完一本书会有 2~4 秒随机等待（模拟人工操作）
  - 每 50 本保存一次进度（进度_50.xlsx、进度_100.xlsx …）
  - 全部完成后生成最终文件：书目搜索结果.xlsx
  - 如果中途中断，再次运行会自动从断点继续（断点续传）


【第四步：查看结果 Excel】
---------------------------------------------------
  颜色说明：
    蓝色  = 原来已标记"OK 找到"的书
    绿色  = 本次新搜索到的书（有下载链接）
    红色  = 未找到的书

  下载链接列：点击"点击下载"即可跳转到下载页面


【常见问题】
---------------------------------------------------
Q: 运行时弹出 Cloudflare 验证怎么办？
A: 在弹出的浏览器窗口里手动通过验证，脚本会自动继续。

Q: 搜索太慢？
A: 默认每本 2~4 秒，这是避免被封的必要间隔，请勿修改太小。

Q: 找到的书不对（书名不匹配）？
A: 搜索用的是简化后的书名关键词，少数情况下会匹配到别的书，
   可以自己点链接确认。

Q: 如何只搜索特定分类的书？
A: 在 books_input.csv 里删掉不需要的行，再运行脚本。


文件清单：
  search_anna.py      主搜索脚本
  convert_to_csv.py   文本转 CSV 工具
  books_input.csv     输入书单（需要你准备）
  books_raw.txt       原始文本书单（如果用方法B）
  search_progress.csv 断点续传记录（自动生成）
  书目搜索结果.xlsx   最终输出结果
