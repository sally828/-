# 上海二手房数据分析系统

自动采集上海二手房数据，按 300-500万 / 500-800万 两个预算档分析，输出写入飞书多维表格，生成实地看房精选清单。

## 1. 飞书开放平台：创建应用

### 1.1 进入开放平台

打开 [https://open.feishu.cn/](https://open.feishu.cn/)，用你的飞书账号登录。

### 1.2 创建企业自建应用

1. 点击顶部导航 **「开发者后台」**
2. 点击 **「创建企业自建应用」**
3. 填写应用名称（如：上海房产助手）和描述，点击创建

### 1.3 获取 App ID 和 App Secret

创建成功后，进入应用页面，在 **「凭证与基础信息」** 里找到：

```
App ID：     cli_xxxxxxxxxxxxxxxx   ← 复制填入 FEISHU_APP_ID
App Secret： xxxxxxxxxxxxxxxxxxxxxxx ← 复制填入 FEISHU_APP_SECRET
```

### 1.4 开通多维表格权限

在应用页面，点击 **「权限管理」**，搜索并开通以下权限：

| 权限名称 | 权限标识符 |
|---------|-----------|
| 查看、评论、编辑和管理多维表格 | `bitable:app` |
| 读取多维表格数据 | `bitable:app:readonly`（可选，更安全） |

开通后点击 **「申请上线」** → **「确认发布」**（企业自建应用无需审核，直接发布）。

### 1.5 为应用添加多维表格访问权限

创建完多维表格后（见第2步），进入每张表，点击右上角**「...」→「更多」→「添加文档应用」**，搜索并添加你刚创建的应用，赋予**「可管理」**权限。

## 2. 飞书多维表格：创建4张表

在飞书（或飞书网页版）中创建4个**独立的多维表格**（不是同一个多维表格里的4张子表）：

| 编号 | 表格名称 | 用途 |
|-----|---------|-----|
| 01 | `01_房源总库` | 存储采集的所有二手房原始数据 |
| 02 | `02_区域评分` | 存储各区域综合评分排名 |
| 03 | `03_KOL观点库` | 存储解析的KOL文章信息 |
| 04 | `04_看房清单` | 存储精选的高可信度房源 |

### 获取 Base ID

打开任意一张多维表格，查看浏览器地址栏 URL：

```
https://xxxx.feishu.cn/base/RHrXbXXXXXXXXXXX?table=tblXXXXXXXXXXXXXX
                              ↑                       ↑
                           Base ID                 Table ID
```

- `base/` 后面到 `?` 前面的部分 = **Base ID**（填入 `FEISHU_BASE_ID_*`）
- `table=` 后面的部分 = **Table ID**（填入 `FEISHU_TABLE_ID_*`）

## 4. 填写 config.py

用文本编辑器打开 `config.py`，将 `""` 中的空值替换为你的真实凭证：

```python
FEISHU_APP_ID     = "cli_xxxxxxxxxxxxxxxx"
FEISHU_APP_SECRET = "xxxxxxxxxxxxxxxxxxxxxxx"

FEISHU_BASE_ID_HOUSE     = "RHrXb..."   # 01_房源总库 Base ID
FEISHU_BASE_ID_REGION    = "RHrXb..."   # 02_区域评分 Base ID
FEISHU_BASE_ID_KOL       = "RHrXb..."   # 03_KOL观点库 Base ID
FEISHU_BASE_ID_SHORTLIST = "RHrXb..."   # 04_看房清单 Base ID

FEISHU_TABLE_ID_HOUSE     = "tblXXX..."
FEISHU_TABLE_ID_REGION    = "tblXXX..."
FEISHU_TABLE_ID_KOL       = "tblXXX..."
FEISHU_TABLE_ID_SHORTLIST = "tblXXX..."

CLAUDE_API_KEY = "sk-ant-api03-..."   # KOL解析功能需要，不用可留空
```

```bash
cd shanghai-house-hunter

```

程序会显示交互式菜单：

```
╔══════════════════════════════════════════════╗
║      上海二手房数据分析系统 · 主菜单          ║
╠══════════════════════════════════════════════╣
║  1. 全量运行（采集 → 评分 → 验证 → 输出）    ║
║  2. 仅运行贝壳数据采集                        ║
║  3. 解析 KOL 文章（粘贴文本）                 ║
║  4. 重新计算评分和看房清单                    ║
║  5. 查看当前统计摘要                          ║
║  0. 退出                                      ║
╚══════════════════════════════════════════════╝
```

### 推荐的首次使用流程

1. 选 **2**，先运行采集，确认数据能正常写入飞书
2. 选 **5**，查看摘要确认数据量正常
3. 选 **3**，粘贴 1-2 篇小红书/公众号房产文章，测试 KOL 解析
4. 选 **4**，重新计算评分并生成看房清单
5. 打开飞书 **04_看房清单** 表格，查看精选结果

## 7. 常见问题

**Q: 运行后报 `飞书 API 错误 code=99991663`？**
A: token 无效，检查 `FEISHU_APP_ID` 和 `FEISHU_APP_SECRET` 是否填写正确。

**Q: 报 `code=1254303` 或字段不存在错误？**
A: 飞书表格中的字段名与代码不匹配，对照第3节字段清单逐一检查，注意括号和中文全角/半角。

**Q: 贝壳采集结果为空？**
A: 贝壳网可能更新了页面结构，可在 `scraper_ke.py` 中调整 CSS 选择器。也可先用浏览器打开目标URL，检查页面是否需要登录或出现验证码。

**Q: KOL解析一直报错？**
A: 检查 `CLAUDE_API_KEY` 是否有效，以及账户是否有余额。

**Q: 运行很慢？**
A: 贝壳采集有 2-5 秒随机延迟（合规要求），7个区域 × 2个价格档 × 10页 = 约140次请求，预计 5-12 分钟。可在 `config.py` 中减少 `KE_MAX_PAGES` 加快速度。

**Q: 错误日志在哪？**
A: 所有异常都记录在项目目录下的 `error.log` 文件中。
